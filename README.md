# Homebrew tap `texstudio-org/texstudio`

Provide [`texstudio`](https://github.com/texstudio-org/texstudio) casks:

- `texstudio`: stable releases only
- `texstudio@beta`: prereleases only
- `texstudio@all`: both stable and pre-releases

Casks are conflict with each other.

## Install casks

```shell
brew install texstudio-org/texstudio/<cask>

# or
brew tap texstudio-org/texstudio
brew trust texstudio-org/texstudio
brew install <cask>
```

> [!NOTE]
> Before the core `Homebrew/cask/texstudio` cask was disabled on 2026-09-01, `brew install texstudio` always resolves to the cask in `Homebrew/cask`.
